Architecture

Frontend SPA

Three builds of the same app using React, Angular, and Vue — each wired to Bootstrap + Tailwind CSS and enhanced with jQuery interactions.

Backend APIs

Express (Node) exposes REST + GraphQL toward MongoDB & PostgreSQL. Spring Boot (Java) serves REST + GraphQL on MySQL. Laravel (PHP) bridges both SQL engines.

Datastores

PostgreSQL & MySQL for relational data (properties, agents, visitors). MongoDB for flexible listing documents and analytics.

Microservices

Ruby (Sinatra) delivers market analytics and customer reviews. All services expose a unified CORS-enabled API surface.
