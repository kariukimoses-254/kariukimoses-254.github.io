📋 Guidance Sheet

1. Register: New patients should create an account on the Register page with a valid email.

2. Login: Sign in at Login using your email and password.

3. Find a Doctor: Browse Doctors, filter by qualification, and rate them.

4. Book an Appointment: On the Appointments page, pick a qualification, a doctor, date, and time.

5. Staff Dashboard: Admins/staff log in and manage patients, doctors, appointments, applications, and records.

6. Doctor Applications: Prospective doctors apply via Doctor Apply and are reviewed by staff.

7. Visiting Hours: Open 24/7; OPD 08:00–20:00, ICU restricted as listed on About.

Web Development Technologies

WEB DEVELOPMENT

→ BACK END (server, database, APIs, application logic)

  • API: GraphQL, REST API
  • Database: PostgreSQL, MySQL, MongoDB
  • Programming Languages: Java, PHP, JavaScript (Node.js), Ruby

→ FRONT END (what users see and interact with in the browser)

  • Libraries: Bootstrap, Tailwind CSS, jQuery
  • Frameworks: Angular, Vue, React
  • Languages: HTML, CSS, JavaScript

Technologies This Site Uses

🌐 Front end: HTML, CSS, JavaScript (plain, no framework)

🗄️ Backend: JavaScript (Node.js) with Express

💾 Database: MySQL (via the mysql2 client)

🖼️ Extras: local images, emoji reactions, dark mode, animation effects

Everything Available on This Site

🏠 Home: overview, stats, services gallery, and a left side panel with Patients/Doctors/Dashboard quick links.

ℹ️ About: hospital info, mission, vision, Quality Goals, visiting hours.

💉 Services: department cards with photos and facilities.

👨‍⚕️ Doctors: photo, specialization, rating (staff & patient), availability, and star rating.

📝 Doctor Apply: doctors submit applications with photo; staff can approve/reject.

📅 Appointments: logged-in patients book by qualification sector; their own history shown.

👤 Register / Login: new emails allowed; admin/staff/patient roles; hashed passwords.

💬 Messages: contact-form messages stored privately per email; My Messages page.

📂 Records: department-wise patient records stored in the database.

📊 Database: live table counts at db.html.

⚙️ Staff Dashboard (left sidebar): patients, doctors, appointments, applications, records, messages.

🎨 Design: dark/light mode, morphing background photos, animations, reactions, help button, toast, confetti.
