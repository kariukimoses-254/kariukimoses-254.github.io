About Me

A bit more about who I am and how I build

KM

Work With Me →

I'm a passionate web developer based in Nakuru, Kenya, focused on creating responsive and accessible web applications. I enjoy learning new technologies and building practical solutions that solve real-world problems.

I work across the whole stack: semantic, accessible markup and smooth interactions on the front end, and REST APIs, authentication and relational data on the back end with Node.js, Express and MySQL. I also build component-driven UIs with React.

I care about the details — loading speed, keyboard accessibility, clean structure and consistent design. When I'm not coding, I'm exploring new ideas and sharpening my craft.

  • Responsive, mobile-first layouts that work on every device
  • Clean, semantic and accessible markup
  • Interactive UI and animations with vanilla JavaScript and React
  • REST APIs, JWT authentication and MySQL data modelling with Node.js & Express
  • Version control and collaboration with Git & GitHub
